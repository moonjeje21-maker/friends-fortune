# friends-fortune 디자인 계획 (design-plan)

> **상태: 1·2·3·4차 모두 구현 완료.** 아래 "현재 화면"이 최종 상태이고, 1~4차는 진행 기록이다. 남은 작업은 [gif-plan](friends-fortune-gif-plan.md)의 "남은 작업"에 있다.
> 2차에서 1차 내용 일부(타이틀 영어 병기, "다시 고르기 · Pick again" 버튼, 카드 구성 표)를 바꿨다.

## 현재 화면 (최종)
- 상단: FRIENDS 로고(`images/friends-bg.jpg`, 가장자리 radial mask) → 타이틀 "오늘의 프렌즈의 말"
- 고르기: 센트럴 퍼크 머그잔 6잔(노·파·빨 반복), 480px 이하에서는 3잔씩 두 줄
- 결과: 대사 박스(대사 인물 GIF(GIPHY MP4, 조연 대사는 없음) + ☕ 점수 + 가장 큰 영어 대사 + 작은 번역 + 말한 사람) → 박스 밖 해석(영어 크게, 한국어 작게) → `Pick again` 버튼 → `S01E19 · 에피소드 제목` 한 줄(11px, 회색). 결과 화면에서는 타이틀을 숨긴다
- 다크 테마 하나, 바탕색 `#060407`(로고 이미지와 동일)
- 해석 영어는 Fraunces 정체(600)라 굵게 보인다. 필요하면 기울임체로 바꿀 수 있다.

## 1차: 커피잔 고르기 디자인
### Context
대사 기반 운세 200개로 데이터를 바꾼 뒤(`fortunes.js`), 화면도 새로 꾸민다.
- FRIENDS 로고 이미지를 배경에 쓴다.
- 커피잔 여러 잔 중 하나를 골라 뽑는 방식으로 바꾼다.
- 타이틀은 "오늘의 프렌즈의 말"로 단순하게 한다.
- 등급 글자(대길·길 등)와 행운의 아이템은 뺀다.
- 대사는 크게, 번역은 작게 보여준다.

### 결정된 사항 (사용자 확인 완료)
- '해석을 작게'는 **한국어 번역**을 작게 한다는 뜻이다. 운세 문장은 중간 크기로 유지한다.
- 카드 맨 위 **☕ 점수(1~5)는 유지**하고, 등급 글자만 삭제한다.
- 배경 로고는 **화면 위쪽 머리 부분에 크고 선명하게** 둔다. 타이틀·커피잔·카드는 로고 아래에 와서 글자와 로고가 겹치지 않는다.
- 커피잔은 **센트럴 퍼크 머그잔** 모양을 CSS로 그린다. 받침 접시가 있고, 머그 색은 노랑·파랑·빨강을 번갈아 쓴다.
- 타이틀도 **한/영 병기**한다: "오늘의 프렌즈의 말" 아래에 작게 "Friends' Line of the Day".
- **다크 테마 하나로 통일**한다(라이트 모드 삭제).

### 1. 화면 흐름
1. 처음 화면: 위쪽 FRIENDS 로고 → 타이틀 → 센트럴 퍼크 머그잔 6잔(프렌즈 6명).
2. 잔을 클릭하면 그 잔이 들썩이고(약 0.5초) 나머지 잔은 흐려진다.
3. 커피잔 자리에 결과 카드가 아래에서 페이드인으로 떠오른다.
4. "다시 고르기" 버튼을 누르면 커피잔 6잔 화면으로 돌아간다.
- 어느 잔을 골라도 결과는 200개 중 무작위다. 직전 결과와 같은 대사는 다시 뽑지 않는다(기존 `lastIndex` 로직 재사용).

### 2. 배경
- 첨부 이미지(2000×1500)를 `friends-fortune/images/friends-bg.jpg`로 저장한다. 맨 아래 저작권 문구 줄은 `sips`로 잘라낸다.
- 페이지 바탕은 이미지와 같은 검은색(#070608 근처)으로 한다.
- 로고는 화면 위쪽에 크게 선명하게 보여주고(좌우 여백이 많은 원본은 로고 부분 위주로 잘라 쓴다), 그 아래는 같은 검은 바탕이 이어진다.
- 로고의 점 색(노랑 #F5D90A · 파랑 #2B3A67 · 빨강 #C8231F)을 포인트 색으로 쓴다. 머그잔 6개도 이 세 색을 번갈아 칠한다(노·파·빨·노·파·빨).
- 배경이 늘 검은색이므로 다크 테마 하나로 통일한다. 라이트 모드는 삭제한다.

### 3. 상단 타이틀
- "오늘의 프렌즈의 말" + 아래에 작게 "Friends' Line of the Day"만 남긴다. 버튼도 "다시 고르기 · Pick again"처럼 한/영 병기.
- "Season 1 · 시즌 1" 문구와 에피소드·운세 개수 문구는 삭제한다.

### 4. 결과 카드 (위 → 아래)
| 요소 | 크기 | 변경 |
|---|---|---|
| ☕ 점수 | 현재 그대로 | 유지 |
| 등급 글자 | – | 삭제 |
| 영어 대사 | 약 24px, 가장 크게 | 확대 |
| 한국어 번역 | 약 13px | 축소 |
| 말한 사람 | 작게 | 유지 |
| 운세 문장(한/영) | 중간 | 유지 |
| 행운의 아이템 | – | 삭제 |
| 에피소드 정보 | 작게, 맨 아래 | 유지 |

### 5. 바뀌는 파일
- `index.html`: 타이틀을 바꾸고, 뒤집히는 카드(front/back) 구조를 커피잔 6개와 결과 카드 영역으로 바꾼다.
- `style.css`: 배경, CSS로 그린 머그잔(몸통·손잡이·받침 접시), 들썩임 애니메이션, 새 카드 글자 크기를 넣는다. 카드 뒤집기 스타일은 삭제한다.
- `app.js`: 잔 클릭 → 뽑기 → 카드 표시, "다시 고르기" → 커피잔으로 복귀. `GRADE_LABEL`과 행운의 아이템 렌더는 삭제한다. 모든 문자열은 계속 `escapeHtml()`을 거친다.
- `CLAUDE.md`: 새 구조와 JS↔CSS 애니메이션 시간표를 갱신한다.
- `fortunes.js`: 변경 없음. `lucky` 데이터는 남아 있지만 화면에서 쓰지 않는다.

### 6. 확인 방법
- 브라우저에서 잔을 여러 번 골라 보고, 가장 긴 대사도 카드에 잘 들어가는지 확인한다.
- 휴대폰 폭(약 375px)에서는 커피잔이 3잔씩 두 줄로 보이는지 확인한다.
- 키보드 Tab/Enter로도 잔을 고를 수 있는지 확인한다(잔은 `<button>`).
- 콘솔 오류가 없는지 확인한다.

### 참고
FRIENDS 로고는 워너브라더스 상표다. 개인용으로는 문제없지만 공개 배포한다면 로고 대신 비슷한 글꼴을 쓰는 편이 안전하다.

- 구현 중 추가: 바탕색을 로고 이미지와 같은 `#060407`로 맞추고 로고 가장자리에 radial mask를 씌웠다.

## 2차: 결과 화면 — 대사를 주인공으로
### Context
커피잔을 고른 뒤 나오는 결과 화면에서 **대사가 가장 눈에 띄게** 한다. 지금은 대사, 운세(해석), 에피소드 정보가 한 박스에 모두 들어 있다. 앞으로 박스에는 대사만 남기고 나머지는 박스 밖으로 뺀다.

### 결정된 사항 (사용자 확인 완료)
- 배치 순서: **대사 박스 → 해석 → 에피소드명 → 버튼**
- ☕ 점수(1~5)는 **박스 안 맨 위에 그대로** 둔다.
- '해석'은 운세 문장(`f.en` / `f.ko`)을 가리킨다.

### 화면 구성
```
┌───────────────────────────┐
│        ☕☕☕☕☕            │
│ "Sometimes just things    │  ← 영어 대사: 가장 크게 (약 26px)
│  doesn't work out."       │
│ 가끔은 그냥 안 되는 일도 있어  │  ← 한국어 번역: 작게 (13px)
│ — Monica · 모니카           │  ← 말한 사람: 작게
└───────────────────────────┘
 Some things won't work out      ← 해석 영어: 크게 (약 17px, 대사보다는 작게)
 however hard you try.
 애써도 안 풀리는 일이 있어요.      ← 해석 한국어: 작게 (13px)

 S01E22 · The One with the Ick Factor   ← 에피소드: 작고 흐리게 (12px)

          [ Pick again ]
```

### 변경 항목
1. **대사(박스 안)**: 영어 대사를 약 26px로 더 키우고, 한국어 번역은 13px로 작게 둔다.
2. **해석(박스 밖)**: 영어를 위에 크게(약 17px), 한국어를 아래에 작게(13px) 둔다. 지금은 한국어가 위에 크고 영어가 아래에 작은데, 이 순서와 크기를 뒤바꾼다.
3. **에피소드명(박스 밖)**: `S01E22 · The One with the Ick Factor` 한 줄만 쓴다. `moment`(한/영 장면 설명)는 표시하지 않는다.
4. **버튼**: "다시 고르기 · Pick again"을 `Pick again`으로 바꾼다.
5. **타이틀**: "오늘의 프렌즈의 말" 아래의 영어 줄 `Friends' Line of the Day`를 삭제한다.
6. 해석과 에피소드는 박스 밖에 테두리 없이 가운데 정렬로 둔다.

### 바뀌는 파일
- `app.js` `render()`: 결과를 박스(`.card`) 하나 대신 `.card`(☕ + 대사) + `.fortune` + `.episode` 세 덩어리로 그린다. 세 덩어리를 감싸는 `#result` 컨테이너는 `hidden`/`aria-live`를 그대로 쓴다. 모든 문자열은 `escapeHtml()`을 거친다.
- `index.html`: `#result`를 `<article class="card">`에서 박스 없는 `<section class="result">`로 바꾸고, 버튼 문구와 `h1` 안의 `<span>`을 수정한다.
- `style.css`: `.result`(세로 정렬, 페이드인 `rise` 애니메이션은 여기로 옮김), `.card`(대사 박스), `.fortune`(박스 밖 해석), `.episode`(에피소드 한 줄), `.line-en` 크기를 조정한다. 쓰지 않는 `h1 span`, `.card footer` 스타일은 삭제한다.
- `CLAUDE.md`: 결과 화면 구성 설명을 한두 줄 갱신한다.
- `fortunes.js`: 변경 없음. `moment`와 `lucky`는 데이터에 남지만 화면에서 쓰지 않는다.

### 확인 방법
- 로컬 서버(`python3 -m http.server`)로 열어 잔을 골라 보고, 결과 화면 스크린샷 한 장으로 순서와 크기를 확인한다.
- 가장 긴 대사로 한 번 렌더해 화면이 옆으로 밀리지 않는지 확인한다.
- "Pick again"을 누르면 커피잔 화면으로 돌아가는지 확인한다.
- 토큰을 아끼기 위해 스크린샷은 축소(0.5배)로 2~3장만 찍는다.

## 3차: 결과 화면 GIF
대사 박스 맨 위에 대사를 말한 인물의 프렌즈 GIF를 넣었다. 자세한 계획과 결정 사항은 `plans/friends-fortune-gif-plan.md`에 있다.
- 출처: GIPHY Friends Season 1 에피소드 24개의 GIF 300개 (`gifs.js`)
- 같은 에피소드의 그 인물 GIF → 없으면 다른 에피소드의 그 인물 GIF → 조연은 GIF 없음
- GIF 대신 같은 장면의 MP4(`<video autoplay loop muted playsinline>`)를 6:5 비율로 보여 주고, 오른쪽 아래에 `via GIPHY` 출처 링크를 단다

## 4차: 결과 화면 정리
- 결과 화면에서는 타이틀 "오늘의 프렌즈의 말"을 숨긴다. `Pick again`을 누르면 다시 보인다.
- 에피소드명은 `Pick again` 버튼 아래로 옮기고, 11px 회색으로 줄인다. 에피소드 코드도 빨간색에서 회색으로 바꾼다.
